# 🔧 Помощник по домашнему ремонту

Веб-сервис на Streamlit для диагностики и решения бытовых проблем с использованием Vision LLM (Claude, OpenAI).

## 🎯 Основные возможности

- **Vision LLM анализ** - Распознавание объектов и проблем на фотографиях
- **Интерактивная диагностика** - Агент-диагност задает уточняющие вопросы
- **Система безопасности** - Автоматическое определение опасных ремонтов (электричество, газ)
- **Генерация инструкций** - Пошаговые инструкции по ремонту на основе RAG
- **Список покупок** - Автоматическое формирование списка инструментов и материалов
- **Агент-сметчик** - Оценка стоимости ремонта

## 🚀 Быстрый старт

### 1. Клонируйте репозиторий

```bash
git clone <repository-url>
cd project_llm_cl
```

### 2. Создайте виртуальное окружение

```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

### 4. Настройте API ключи

Создайте файл `.env` в корне проекта (используйте `.env.example` как шаблон):

**Вариант A: Claude (рекомендуется)**
```bash
LLM_PROVIDER=claude
CLAUDE_API_KEY=ваш_ключ
CLAUDE_BASE_URL=ваш_url
```

**Вариант B: OpenAI**
```bash
LLM_PROVIDER=openai
OPENAI_API_KEY=sk-ваш_ключ
```

### 5. Запустите приложение

```bash
streamlit run main.py
```

Приложение откроется в браузере по адресу `http://localhost:8501`

## 📋 Требования

- Python 3.8+
- API ключ для **Claude** или **OpenAI GPT**

## 🏗️ Архитектура проекта

Проект разделен на модульные компоненты для удобной командной работы:

```
project_llm_cl/
├── main.py                    # 🎨 Frontend: Streamlit UI и основной flow
├── config.py                  # ⚙️ Конфигурация: настройки и константы
├── llm_client.py              # 🤖 LLM: унифицированный клиент для Claude/OpenAI
├── vision_analyzer.py         # 👁️ Vision: анализ изображений
├── diagnostic_agent.py        # 🔍 Диагностика: интерактивные вопросы
├── safety_checker.py          # ⚠️ Безопасность: проверка опасных ремонтов
├── instruction_generator.py   # 📖 RAG: генерация инструкций
├── shopping_agent.py          # 🛒 Сметчик: список покупок и цены
├── requirements.txt           # Зависимости Python
├── .env                       # API ключи (не в git!)
├── .env.example               # Шаблон для .env
└── README.md                  # Документация
```

### Распределение работы в команде

Каждый модуль независим и может разрабатываться отдельно:

1. **Frontend разработчик** → `main.py`
   - Улучшение UI/UX
   - Добавление новых экранов
   - Визуализация данных

2. **RAG специалист** → `instruction_generator.py`
   - Интеграция с реальными базами знаний (iFixit, WikiHow)
   - Векторные базы данных (ChromaDB, Pinecone)
   - Улучшение качества инструкций

3. **Агент-сметчик** → `shopping_agent.py`
   - Интеграция с API магазинов
   - Парсинг цен
   - Оптимизация списка покупок

4. **Vision & Диагностика** → `vision_analyzer.py`, `diagnostic_agent.py`
   - Улучшение промптов
   - Мультимодальный анализ
   - Логика уточняющих вопросов

5. **Безопасность** → `safety_checker.py`
   - Расширение базы опасных ситуаций
   - Улучшение предупреждений

## 🔑 Настройка API

### Claude (рекомендуется)

**Преимущества:**
- Отличное качество ответов
- Поддержка Vision
- Стабильная работа

**Настройка:**
```bash
LLM_PROVIDER=claude
CLAUDE_API_KEY=ваш_ключ
CLAUDE_BASE_URL=ваш_url
```

**Модели:**
- Vision & Text: `claude-haiku-4-5-20251001`

### OpenAI GPT

**Преимущества:**
- Высокое качество ответов
- GPT-4o с vision
- Широкая доступность

**Получение ключа:**
1. Перейдите на https://platform.openai.com/api-keys
2. Создайте новый ключ
3. Скопируйте (показывается только один раз!)

**Настройка:**
```bash
LLM_PROVIDER=openai
OPENAI_API_KEY=sk-ваш_ключ
```

**Модели:**
- Vision: `gpt-4o`
- Text: `gpt-4o-mini` (быстрее и дешевле)

**Стоимость:**
- GPT-4o: ~$2.50 за 1M input tokens
- GPT-4o-mini: ~$0.15 за 1M input tokens
- Одна диагностика ≈ $0.01-0.05

## 🔑 Ключевые компоненты

### Vision Analyzer (`vision_analyzer.py`)
- Анализ изображений с помощью Vision LLM
- Определение объекта/устройства и проблемы
- Оценка уровня опасности

### Diagnostic Agent (`diagnostic_agent.py`)
- Генерация уточняющих вопросов
- Анализ ответов пользователя
- Уточнение диагноза

### Safety Checker (`safety_checker.py`)
- Определение опасных ремонтов (электричество, газ)
- Генерация предупреждений
- Рекомендации по безопасности

### Instruction Generator (`instruction_generator.py`)
- Генерация пошаговых инструкций
- RAG для поиска в базе знаний
- Список инструментов и материалов

### Shopping Agent (`shopping_agent.py`)
- Формирование списка покупок
- Оценка стоимости материалов
- Рекомендации магазинов

## 📝 Примеры использования

### Пример 1: Протекающий кран
1. Загрузите фото протечки
2. Система: "Смеситель, протечка из-под гайки"
3. Вопросы: "Когда началась протечка?", "Капает постоянно или при включении?"
4. Инструкция: Замена прокладки
5. Список: фум-лента, разводной ключ (~200-500₽)

### Пример 2: Ошибка стиральной машины
1. Фото дисплея с кодом E15
2. Система: "Bosch, ошибка Аквастоп - вода в поддоне"
3. Вопросы: "Есть ли вода под машиной?"
4. Инструкция: Слив воды, перезагрузка датчика
5. Инструменты: отвертка Torx, тряпка

## 🔒 Безопасность

Система автоматически определяет опасные ремонты:
- Электричество (провода, розетки, щитки)
- Газ (утечки, котлы, колонки)
- Высокое напряжение

При обнаружении опасности выводятся предупреждения и рекомендации.
